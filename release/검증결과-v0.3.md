# PHYSIS AI v0.3 Windows x64 검증 보고서

2026년 11월 25일. 자연어 질문, 문헌 원문, 레지스트리 공식, 물리 엔진의 실행값, 근거 패널을 실제 로컬 앱에서 연결해 확인했습니다. 기본 실행은 Mock입니다. 실제 공급자의 추론 정확도와 교육 효과는 미측정입니다.

실제 Microsoft Edge를 Playwright로 구동했습니다. Windows ZIP을 한국어·공백 경로에 풀고 앱의 PATH에서 시스템 Python과 Node를 제거했습니다. 테스트 드라이버는 별도의 개발 환경, 서버와 기호 계산 워커는 배포된 내장 런타임을 사용했습니다.

| 시나리오 | 확인한 사용자 동작 |
|---|---|
| A · 뉴턴 운동 법칙 | 튜터 질문 → 실제 실험과 공식 → 영어 교재 구절·위치 확인 → 실행 지문이 있는 보고서 내려받기 → 다른 가속도값 대조 |
| B · 진자 주기 | 소각도 근사식의 적용 범위 밖 표시, 공식 라이브러리에서 변수·조건 확인, 진자 실험으로 이동 |
| C · 가상 문헌 | 존재를 확인할 수 없는 문헌 요청에 검증 인용 0개 표시 |
| D · 잘못된 수치 | 루프백 호환 공급자가 의도적으로 99와 없는 출처를 SSE로 반환. 실제 검증기가 원래 계산값을 보존하고 실패와 기준값을 화면에 표시 |
| E · 미지원 시뮬레이션 | 공기 저항을 포함한 낙하 요청에서 이론 독서 자료와 계산 미지원이 각각 표시됨 |
| F · 수학 기초 | 벡터 선행 학습 → 읽을 자료 → 오답 제출과 복습 추천 → 정답 제출 및 진도 갱신 → 기초 수학 도구 실제 실행 |
| G · 오프라인 | API 키 제거, 서버의 외부 DNS·연결 차단, 브라우저의 외부 요청 차단 상태에서 내장 자료, 기본 실험, Mock 대화, 미분 연산 실행 |

추가 브라우저 검사에서 전체 27개 공식의 LaTeX 렌더링, 진자식 선택, 약분 전 정의역 검사, 불연속 그래프와 이분법 결과를 확인했습니다. 브라우저 시험 수는 테스트 함수·매개변수 조합입니다. C와 E는 연속 질문으로 한 시험에서 수행했습니다. 같은 PC에서 소프트웨어로 연결을 차단했으며 네트워크 어댑터를 끄거나 새 Windows를 설치하지는 않았습니다.

| 배포본 | SHA-256 |
|---|---|
| 0.1 | `f75e3b0769339a700862e2479397a23df5c0c1d9ea2a7c7c566859e70e1552d3` |
| 0.2 | `b9c540bc2cafccd1272b4d98f4c2fcf4b6d5257ae0882751215d86e2d857fc4c` |

1. 새 독립 문항으로 모호한 질문의 재질문과 측정 자료가 부족할 때의 답변 보류를 개선합니다.
2. 교사가 인용의 실제 지지 여부와 공식 적용 조건을 독립 판독하고, 외부 공급자 사용 승인이 있을 때 같은 모델의 단독·검색·검색+계산 세 조건을 비교합니다.
3. 별도 Windows PC에서 설치·접근성을 확인하고 실제 학습자의 사전·사후 문제 풀이를 측정합니다.
