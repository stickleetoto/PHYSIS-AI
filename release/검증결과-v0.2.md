## 관찰한 결과

- 낙하 높이 20 m와 5 m에서 두 물체의 도착 시간은 각각 약 2.0193 s, 1.0096 s였다. 네 실험을 같은 시계로 진행했을 때 짧은 실험은 마지막 표본에서 멈췄다. 각 실험의 CSV 끝 시각과 계산 결과가 일치했다.
- 튜터가 0.2~0.8 s를 강조하면 높이 그래프에 해당 구간을 표시했다. 0.6 s 이동·일시정지 요청은 장면의 재생 위치에 반영됐다. 설명은 엔진이 기록한 시점과 수치를 사용했다.
- 13개 기본 모델의 공식이 KaTeX와 MathML로 렌더링됐다. 수치해석실에서 네 방법의 시간·오차와 수렴 곡선을 읽었다. 허용 범위의 불안정한 계산에서도 매우 큰 유한 오차를 표시했다.
- 발견 학습에서 가설을 저장하고 관찰·결론을 연결했다. 과거 가설을 물었을 때 현재 실험의 기록을 회상했다. 오답을 선택하면 복습 대상으로 기록됐다. JSON에 가설·답변·실험 입력·사용 기록이 포함됐고, 전체 삭제 뒤 서버 내보내기가 비어 있음을 확인했다.
- 공급자 통신은 분할·중단·잘림·시간 초과·거부를 포함한 모의 HTTP 응답으로 검증했다. 실제 루프백 서버의 느린 튜터 해석 중 클라이언트 연결을 끊었을 때 처리가 취소됐고 입력과 버전이 보존됐다.

## 실행 환경과 한계

Windows x64, CPython 3.13.4, Node.js 24.18.0, Edge 158.0.4370.33. ZIP을 공백과 한글이 있는 별도 폴더에 풀었다. 테스트 구동기는 호스트 Playwright를 사용했고, 앱은 시스템 Python과 Node를 PATH에서 제외한 상태에서 `Start-PHYSIS.cmd`와 번들 Python으로 실행했다. 새 Windows PC 설치와 실제 휴대전화는 미검증이다. 모바일 레이아웃은 390 × 844 브라우저 뷰포트에서 확인했다.

OpenAI·Anthropic·Ollama·OpenAI 호환 서비스의 실제 계정 인증, 모델별 응답 품질, 수업에서의 학습 효과는 미측정이다. 교육 점수는 공개 교재식과 기대값을 지정한 고정 개발 문항의 결과다. [교육 평가 기준](../EDUCATIONAL_EVALUATION.md) · [물리 검증 기준](../PHYSICS_VALIDATION.md) · [알려진 한계](../KNOWN_LIMITATIONS.md)
