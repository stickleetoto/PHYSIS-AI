# PHYSIS AI v0.4 · Windows x64 배포 검증

기준 소스는 로컬 v0.3.3 커밋 `baf3b7cc350b13e38be60dc515c171801fca4d16`이다. 브랜치는 `feature/v0.4-mathematics-lab`이다. 교육 예제 10개 분야를 한국어 워크벤치에서 실행한다. 배포 ZIP에는 소스, 테스트, 프런트엔드 번들, Windows x64 CPython, 기존 의존성과 로컬 글꼴을 넣는다.

| 항목 | 검증 방법 |
|---|---|
| 백엔드 | `python -X utf8 -m pytest -q backend/tests`를 한 프로세스로 실행. 전체 570개 통과 |
| 프런트엔드 | Vitest 단일 워커. 8개 파일, 32개 통과 |
| 배포용 UI | `tsc --noEmit` 및 Vite 프로덕션 빌드 통과 |
| 소스 브라우저 | Windows 런처와 실제 로컬 API에 연결한 Edge/Chromium. 기초 실험·공식 라이브러리·수치해석·저장과 내보내기·수학 화면 등 23개 시나리오 |
| 압축 해제 후 실행 | 소스 실행과 별도로 동일한 수학 시나리오 4개를 배포 폴더의 런처와 내장 Python에서 재실행. 시스템 Python을 PATH에서 제외 |
| 아카이브 검사 | 전체 ZIP CRC, 중복·비공개 파일, 내장 python.exe의 AMD64 PE 헤더, 패키지 내 프로젝트 파일과 소스의 바이트 일치 검사 |
| 호환성 | 배포본의 모델 23개·공식 27개를 레지스트리에서 조회. 이전 배포 ZIP 여섯 개의 SHA-256을 이전 배포 기록과 대조 |
| AI·GPU | Mock/저장 응답, 브라우저 GPU·WebGL·가속 캔버스 비활성화. 실제 LLM 추론·학습·모델 다운로드·유료 API 호출 0회. 교육 효과와 모델 성능은 미측정 |

검사 과정에서 분기점 좌우 기울기가 같은 점프, 부호가 바뀌는 원시함수, 주기함수의 진동 극한을 별도 사례로 추가했다. 첫 배포 후보에서는 브라우저 4개 중 3개가 실패했다. 기본 함수의 서버 응답에서 라이브러리 로딩과 수식을 합산한 8초 제한 초과를 확인했다. 반복 측정 한 번에서는 내장 Python의 SymPy 로딩에 1.56초, 식 계산에 0.37초가 걸렸다. 최종 워커는 고정 라이브러리 시작(최대 18초)과 사용자 수식 계산(최대 8초)을 분리하고 취소된 작업의 자리가 반환될 때까지 최대 0.6초 기다린다.

ZIP 작성 후 생성하는 `browser-v04-packaged.json`에는 아카이브의 실제 바이트 수, 파일 수, SHA-256, 확인한 이전 배포본의 해시, 소스·배포본 실행 결과를 기록한다. 이 파일은 ZIP 옆에 둔다.
