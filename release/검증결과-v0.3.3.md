# PHYSIS AI v0.3.3 편의성 패치

기준은 `v0.3.2` 태그의 커밋 `020fb63c6ddc2c24ee736b8debf24d128539617a`다. 기존 물리 모델 23개와 공식 27개를 사용한다.

## 검증한 사용자 동작

| 기능 | 확인한 내용 |
|---|---|
| 실험 저장·불러오기 | 단일 실험과 비교 그룹의 입력·계산법·시간 격자·사용자 이름·순서·활성 실험 및 비교 보기를 저장한다. 현재 물리량과 물체 선택을 복원한다. 잘못된 버전·입력·참조·파일 크기·중복 키를 거부하며, 두 번째 실험이 실패해도 일부만 저장하지 않는다. |
| 실행 취소·다시 실행 | 직접 편집과 Mock의 변경을 같은 이력에 쌓는다. 과거 입력 복원, 새 변경 뒤 다시 실행 취소, 별도 실험으로 전환, 이전 버전 DB 열기, 50개 보관 상한을 검사했다. |
| PNG·CSV | 화면의 현재 장면과 그래프를 별도 이미지로 저장한다. 제목·단위·가정·검증 상태 및 그래프 계열을 확인했다. 파동·유체 장면의 PNG와 기존 CSV 다운로드도 검사했다. |
| 키보드 | Space, R, N, Ctrl+Z/Y/S/O로 실제 재생·초기화·복원·파일 대화상자를 조작했다. 질문 입력 중 키를 눌러 실험 시간이 움직이거나 조건이 바뀌는지도 확인했다. |
| 학습 프리셋 | 등록된 23개 모델과 프리셋의 일대일 대응, 관찰량·초기 조건의 등록 범위, 프리셋으로 실험 열기를 확인했다. |
| 단위 변환 | 길이·질량·시간·속도·가속도·힘·압력·에너지·전력·온도·밀도·각도. 섭씨·화씨·켈빈 변환과 차원 불일치 거부를 검사했다. |

## 순차 검증

| 검사 | 결과 |
|---|---|
| 백엔드 기존 회귀 및 신규 단위·통합 검사 | 512/512 통과 |
| 프런트엔드 Vitest, 단일 워커 | 24/24 통과 |
| TypeScript 및 Vite 프로덕션 빌드 | 통과 |
| 소스 빌드 Edge 브라우저 시나리오 | 8/8 통과 |

브라우저는 GPU, WebGL, 가속 2D 캔버스를 끈 상태에서 구동했다. 백엔드 회귀 검사는 실제 HTTP 공급자 전송을 차단한 테스트 어댑터를 사용했다. 새 기능의 브라우저 검사는 오프라인 Mock으로 실행했다. 실제 모델 요청·학습·파인튜닝은 0건이며 실제 AI 성능 및 교육 효과는 미측정이다.

## 사용 범위

- 저장 형식 v1은 128 KiB 이하, 비교 구성은 최대 4개다. 읽을 때 새 실험 ID를 발급하고 결과를 다시 계산한다. 대화와 학습 기록, 취소 이력은 파일에 포함하지 않는다.
- 취소 이력은 로컬 DB에서 실험별로 유지된다. 이전 버전에서 이미 덮어쓴 입력은 소급 복원할 수 없다. 재생 시각만 되감으려면 기존 **처음으로** 버튼을 사용한다. **R**은 기본 실험 조건도 복원한다.
- 그래프 PNG는 현재 측정 그래프에서 데이터가 표시될 때 제공된다. 별도 클린 PC 설치와 다른 브라우저 환경은 미검증이다.
